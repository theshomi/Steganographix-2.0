# Steganographix

Офлайн PWA для шифрования и скрытия текста/небольших файлов в PNG/BMP/WebP через RGB LSB.

## Безопасность
- Web Crypto API: AES-256-GCM + PBKDF2 SHA-256, 100000 итераций.
- Соль 16 байт, IV 12 байт, случайность через `crypto.getRandomValues`.
- Пароль не сохраняется.
- Нет аналитики, CDN или API.
- JPEG/сжатие может разрушить LSB.

## Запуск
Для Service Worker нужен HTTPS или localhost. На GitHub Pages приложение работает офлайн после первого посещения.

## Ограничения
Изображение до 20 МБ, файл до 1 МБ, пароль минимум 6 символов. Вместимость зависит от количества пикселей.
